# اختبارات AF Group

اختبارات بتفتح السيستم الحقيقي في متصفح، بداتا وهمية، من غير ما تلمس قاعدة البيانات.

بتشتغل لوحدها على GitHub مع كل تعديل (Actions ← Tests). لو فيه حاجة اتكسرت هتلاقي ❌ وإيميل من GitHub.

بتختبر:
- كل الصفحات بتتقرا من غير أخطاء برمجية.
- مفيش مفاتيح سرية في الملفات اللي بتوصل للمتصفح.
- الخصائص اللي اتعملت لسه موجودة (بتمسك رفع نسخة قديمة من index.html).
- تنسيق الفلوس.
- كل شاشة لكل دور (مالك موبايل وكمبيوتر، محاسب، عامل) بتفتح من غير خطأ ومن غير سكرول بالعرض.
- المحاسب والعامل ما يشوفوش مركز القرار ولا التكاليف.
- شاشة العامل: "شغلك النهارده"، ابدأ، رجّعه، التحذير قبل ما ياخد صنف عامل تاني، واشتغالها لو خدمة التكليفات وقعت.

تشغيل محلي:
```
cd tests/e2e && npm install && npx playwright install chromium && npm test
```
